## Featured Engineering Case Studies

### 01. EUREKA | Semantic Search & NLP Pipeline
> **Second Prize – National Grand Finale | STATATHON 2025–26**
* **The Challenge:** Converting highly unstructured, free-text, and voice-based job descriptions into standardized NCO-2015 occupation codes with high accuracy.
* **The Solution:** Engineered a high-dimensional semantic mapping system utilizing dense vector indexing (`FAISS`). Fine-tuned sentence embeddings to optimize for low-latency similarity search, ranking, and validation.
* **Stack:** `Python`, `Flask`, `PostgreSQL`, `FAISS`, `Sentence Transformers`

### 02. Network Traffic & URL Monitoring Desktop Client
> **Standalone Desktop Utility**
* **The Challenge:** Capturing and organizing live website and API request URLs from active network environments for debugging and telemetry.
* **The Solution:** Developed a dedicated Python-based desktop application featuring a custom UI with state-managed start/stop toggles to monitor, capture, and persistently store URL traffic logs locally.
* **Stack:** `Python`, `Desktop UI Frameworks`, `Network Protocols`

### 03. A1 Water Tech | Commercial Full-Stack Platform
> **Production System for a Real-World Business Client**
* **The Challenge:** Building an adaptable, end-to-end digital infrastructure capable of handling shifting business logic and live consumer transactions.
* **The Solution:** Architected a synchronized suite utilizing React for the web portal and Flutter for the mobile client, tied together by a secure Node.js/Flask backend with live database replication.
* **Stack:** `React`, `Flutter`, `Node.js`, `Flask`, `Firebase`, `MySQL`

### 04. Real-Time API Health Monitor | Distributed Telemetry Service
> **Third Prize | Hackwave 3.0.1**
* **The Challenge:** Tracking API health, latency degradation, and HTTP failure rates in real-time across distributed services.
* **The Solution:** Built a distributed telemetry service providing centralized monitoring, automated alerts, and downtime detection for mission-critical endpoints.
* **Stack:** `Python`, `Flask`, `REST APIs`, `MySQL`
